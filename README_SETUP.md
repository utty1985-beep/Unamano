# UnaMano V4 — installazione

Progetto autonomo. Non usare database, repository o credenziali del Registro Finanziario Familiare.

1. Crea un NUOVO progetto Supabase chiamato UnaMano.
2. In SQL Editor esegui `supabase_schema.sql`.
3. Copia Project URL e Publishable key nel file `config.js` (la publishable key è destinata al client; non inserire service_role o segreti).
4. In Supabase Authentication > URL Configuration imposta Site URL al futuro URL GitHub Pages e aggiungilo ai Redirect URLs.
5. Usa questo repository dedicato esclusivamente a UnaMano.
6. Prima del lancio pubblico completa informativa privacy/cookie, termini, moderazione e contatti del titolare del servizio con dati reali.
