# UnaMano — passaggio futuro a dominio a pagamento

Il progetto è predisposto per partire con l'indirizzo gratuito GitHub Pages e passare successivamente a un dominio proprietario senza riscrivere l'app.

## Strategia
1. Avvio iniziale su GitHub Pages.
2. Test con utenti reali e correzione dei problemi.
3. Scelta del nome definitivo dopo verifica di disponibilità e marchio.
4. Acquisto del dominio presso un registrar.
5. Verifica del dominio nell'account GitHub.
6. Configurazione del dominio in GitHub Pages e dei record DNS presso il registrar.
7. Attivazione HTTPS.
8. Aggiornamento in Supabase di Site URL e Redirect URLs al dominio definitivo.
9. Aggiornamento dei link di condivisione e delle pagine Privacy/Termini.

## Nota
Non acquistare il dominio prima di avere verificato il nome definitivo. Il dominio sarà un costo separato; l'hosting statico può continuare a essere GitHub Pages anche dopo il collegamento del dominio.
