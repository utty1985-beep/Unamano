# UnaMano — passaggio futuro a dominio proprietario

Data aggiornamento: 28/09/2026

Il progetto è predisposto per partire con l'indirizzo gratuito GitHub Pages e passare successivamente a un dominio proprietario senza riscrivere l'app.

## Stato attuale
Nome operativo: **UnaMano**.

Il nome non va ancora considerato definitivamente libero dal punto di vista del marchio o del dominio. Prima di acquistare o registrare qualcosa va effettuata una verifica formale di disponibilità e di eventuali diritti anteriori.

## Candidati da verificare in futuro
Ordine di preferenza indicativo:
1. `unamano.it`
2. `unamano.app`
3. `unamano.social`
4. variante con parola descrittiva, solo se il nome semplice non è utilizzabile.

**Nota:** questa lista non certifica che i domini siano liberi o acquistabili.

## Strategia
1. Avvio iniziale su GitHub Pages.
2. Test con utenti reali e correzione dei problemi.
3. Beta locale.
4. Verifica formale del nome e dei possibili marchi/segni anteriori.
5. Verifica disponibilità dominio presso un registrar.
6. Solo dopo: acquisto del dominio.
7. Verifica del dominio nell'account GitHub.
8. Configurazione GitHub Pages e record DNS.
9. Attivazione HTTPS.
10. Aggiornamento Supabase Site URL e Redirect URLs.
11. Aggiornamento URL in SEO, sitemap, IndexNow, manifest, social preview, Privacy e Termini.
12. Nuova verifica Google Search Console/Bing per il dominio definitivo.

## Regola operativa
Finché non viene scelto il dominio definitivo, tutti i materiali promozionali devono usare il link GitHub Pages oppure testi senza URL stampato in modo permanente.

Non acquistare il dominio prima di avere completato test, beta e verifica del nome.
