# Release notes 6.4.0

- Preparazione completa per Google Play con target Android 16 / API 36.
- Nuovo piano Free / Passione PRO.
- Limite Free di 5 ricerche esterne al giorno, memorizzato nativamente nell'app Android.
- Ricerche esterne illimitate con PRO.
- Google Play Billing integrato per l'abbonamento annuale `passione_pro_annuale`.
- Ripristino acquisto PRO.
- Informativa privacy integrata e pagina Privacy dedicata.
- Consenso esplicito prima dell'invio di foto al servizio esterno di riconoscimento funghi.
- Posizione solo mentre l'app è in uso; nessun permesso di posizione in background.
- Nessun permesso generale di accesso ai file del telefono.
- Traffico HTTP in chiaro disabilitato.
- Backup Android automatico dei dati interni disabilitato; restano i backup espliciti dell'app.
- WebView limitata al dominio dell'app; collegamenti esterni aperti nel browser.
- Aggiornamento grafico di top bar, schede, pulsanti, indicatore Free/PRO e schermata PRO.
- Conservata la v6.3.9 come ramo di backup prima delle modifiche.
