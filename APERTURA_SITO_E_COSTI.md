# Apertura pubblica UnaMano e costi

Data: 27/09/2026

## Stato attuale
UnaMano è già online tramite GitHub Pages e usa Supabase per database, autenticazione e notifiche. Il progetto Supabase dell'account risulta attualmente sul piano Free.

## Strategia consigliata per partire spendendo il minimo
1. Tenere hosting su GitHub Pages: costo hosting iniziale €0.
2. Tenere Supabase Free finché il traffico e l'utilizzo restano entro i limiti del piano: costo iniziale €0.
3. Acquistare solo il dominio professionale, preferibilmente `unamanoitalia.it`, se disponibile.
4. Collegare il dominio a GitHub Pages e attivare HTTPS gratuito.
5. Completare prima del lancio nazionale i dati reali del gestore, recapito, privacy, termini e procedura di segnalazione/moderazione.
6. Non aggiungere tracker pubblicitari o analytics non necessari nella prima fase, così si riduce la complessità cookie/privacy.

## Costo indicativo minimo
- GitHub Pages: €0 per il sito pubblico su repository compatibile.
- HTTPS su GitHub Pages: €0.
- Supabase: piano attuale Free, quindi €0 finché non serve passare a un piano superiore.
- Dominio .it: unico costo necessario per avere un indirizzo professionale. Il prezzo dipende dal registrar e dalle promozioni del momento.

## Prezzo di riferimento verificato il 27/09/2026
Aruba pubblicizza per i domini .it una promozione di 3,99 € + IVA per il primo anno e 11,99 € + IVA al rinnovo. Prima dell'acquisto va verificata la disponibilità effettiva di `unamanoitalia.it` direttamente sul registrar.

## Configurazione tecnica del dominio
Per GitHub Pages, un dominio personalizzato può essere collegato al sito configurando il dominio nelle impostazioni Pages del repository e i record DNS presso il registrar. GitHub supporta HTTPS anche per i custom domain correttamente configurati.

## Prima del lancio pubblico nazionale
- Inserire nome/identità e contatto del gestore nelle pagine legali.
- Verificare Privacy e Termini con i dati reali del titolare.
- Mantenere il modulo Segnala contenuto ben visibile.
- Se in futuro vengono aggiunti cookie o strumenti di profilazione/marketing, implementare il consenso preventivo quando richiesto.
- Eseguire un test completo con almeno due account e due telefoni.

## Lancio gratuito organico
Prima fase senza pubblicità a pagamento:
- Instagram Reel + Story.
- Facebook Reel + post e gruppi locali dove consentito.
- TikTok verticale.
- YouTube Short.
- WhatsApp e condivisione diretta.
- QR code su volantini/materiale locale.

Partire da una o poche città con attività reale, non da tutta Italia in contemporanea.
